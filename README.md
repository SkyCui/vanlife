# 旅居搭子 · 第一版

面向个人、搭子与伴侣的床车/房车旅居规划工具。第一版以夫妻两人实际使用为目标。

## 使用流程

1. 用各自 ChatGPT 账号登录。站点保持私密，访问授权和共同空间邀请是两层权限。
2. 创建者导入示例预算，或新建空白方案；在「空间」中生成48小时有效的一次性邀请链接。
3. 搭子登录后加入共同空间。个人与共有支出独立标记，个人项目可设置仅本人可见。
4. 编辑参数、复制方案、比较现金支出与净成本参考。
5. 在「计划表」中选择生成月度表和看板；月度表可导出CSV，行程与待办支持共同维护。
6. 记录实际收入支出，在「空间」维护个人或共同记忆。
7. 使用助手前确认数据发送至 DeepSeek。参数建议需要手动确认应用。

## 示例预算与隐私

公开仓库使用虚构预算演示计算。启动现金、应急金、车辆购置及各项费用均为示例，需要使用者修改为自己的数据。源码对应已发布第一版的功能；不附带开发者的个人预算、账号、对话、记忆或账本。

## 计算规则

- 年度模块按周期月数/12折算，每日模块按总天数计算。
- 经常性预算以整数分均摊到月，舍入尾差归末月；一次性支出在指定月计入。
- 能源模块支持全程里程×百公里能耗÷100×单价及手动覆盖。
- 车辆购置与改装是否已从启动现金扣除由用户显式选择；残值只用于净成本参考，不计入现金。
- 实际账本和预算预测分开，避免重复扣除；个人私密数据不进入他人的计算或AI上下文。
- 新收入按可用于生活的净收入填写。

## 部署与运行

源码采用Vinext/React，服务端运行在Workers，持久化使用D1。`.openai/hosting.json`保存站点身份与逻辑绑定；密钥作为Sites服务器秘密配置保存。

本地`.dev.vars`仅用于开发，禁止提交或输出其内容。`work/`存放本地测试，排除发布。Drizzle迁移保存于`drizzle/`，生产已应用的迁移不可修改。

## 已验证及限制

数学计算、收入与应急金、车辆口径、能源公式；共同空间与第三账号隔离；私密模块、记忆与收支隔离；并发修改冲突；DeepSeek参数建议与公开搜索；桌面与390像素手机总览；WebMCP读取、比较和参数预览。

公开查询通过搜索来源提供参考，不保证摘要中的价格实时有效。暂未连接银行流水，不自动估算残值、不自动订购、支付或发布。支持行程与待办及月度财务计划，不提供实时导航。

## 本地开发

要求 Node.js 22.13 或更高版本。

```sh
npm ci
cp .dev.vars.example .dev.vars
# 在 .dev.vars 中填入自己的 DeepSeek API key
npm run dev
```

初始化本地数据库（可在启动开发服务器前运行）：

```sh
npx wrangler d1 migrations apply site-creator-d1 --local --config wrangler.local.json --persist-to .wrangler/state
npx tsc --noEmit
npm run build
```

`wrangler.local.json` 仅用于本地迁移，数据库标识为开发占位符。

账号认证依赖 Sites 的 ChatGPT 身份网关，本地由开发插件提供模拟登录。部署到其他平台时，需要实现可信身份网关，并移除客户端传入的身份头，不能直接将 API 暴露在未验证身份的服务器上。`.openai/hosting.json` 是现有站点的部署关联信息，不授予任何访问权限；新建站点需要使用自己的站点标识及数据库绑定。在线站点权限和共同空间邀请分开管理。

服务端环境变量模板见 `.dev.vars.example`。公开搜索返回来源与查询时间，价格仍需核实；AI 提出的预算及行程更改经确认后才保存。
